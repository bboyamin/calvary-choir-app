📲 스마트폰 홈 화면에 앱 추가하기

🍎 아이폰 (iPhone / Safari) 가이드

  1. 화면 하단 중앙의 [공유 📤] 아이콘을 누릅니다.
  2. 메뉴를 위로 올린 후 [홈 화면에 추가 ➕]를 선택합니다.
  3. 우측 상단 [추가]를 누르면 바탕화면에 성가대 앱이 생성됩니다!

🤖 안드로이드 (Galaxy / Chrome / 카카오) 가이드

  1. 인터넷 메뉴 [더보기 ⫶] 버튼을 누릅니다.
  2. [홈 화면에 추가] 또는 [앱 설치]를 클릭합니다.
  3. 바탕화면에 아이콘이 생성되어 다음부터 1초 만에 접속됩니다.
